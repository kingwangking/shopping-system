## 2. 订单核心链路（记录/查询/统计）

```mermaid
sequenceDiagram
    participant Client as Client
    participant Controller as Web Controller
    participant App as Application Use Case
    participant Domain as Domain Model
    participant Repo as Repository
    participant DB as Database

    rect rgb(235, 248, 255)
    note over Client,DB: 记录订单（CreateOrder）
    Client->>Controller: POST /orders
    Controller->>App: createOrder(command)
    App->>Domain: 创建并校验订单规则
    App->>Repo: save(order)
    Repo->>DB: INSERT order
    DB-->>Repo: ok
    Repo-->>App: persisted order
    App-->>Controller: result dto
    Controller-->>Client: 201 Created
    end

    rect rgb(245, 255, 240)
    note over Client,DB: 查询订单（QueryOrders）
    Client->>Controller: GET /orders?conditions
    Controller->>App: queryOrders(query)
    App->>Repo: findByConditions(query)
    Repo->>DB: SELECT ...
    DB-->>Repo: order list
    Repo-->>App: domain objects
    App-->>Controller: list dto
    Controller-->>Client: 200 OK
    end

    rect rgb(255, 248, 235)
    note over Client,DB: 统计订单（GetOrderStatistics）
    Client->>Controller: GET /orders/statistics
    Controller->>App: getOrderStatistics(query)
    App->>Repo: aggregate(query)
    Repo->>DB: SUM/COUNT ...
    DB-->>Repo: statistics rows
    Repo-->>App: statistics data
    App-->>Controller: statistics dto
    Controller-->>Client: 200 OK
    end
```

## 3. 依赖规则提示
- 依赖向内：Interfaces -> Application -> Domain。
- Infrastructure 负责实现接口，不承载业务规则。
- Domain 不依赖框架与数据库。

## 4. 当前阶段约束
- 当前仅聚焦订单子域。
- 仅实现记录、查询、统计三类基础能力。
- 商品、库存、营销、支付等能力暂不纳入。
